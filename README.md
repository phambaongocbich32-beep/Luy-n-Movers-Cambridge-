# Flyers Academy

Web học Cambridge Flyers (giọng Anh–Mỹ): từ vựng có tranh trong sách và loa, ngữ pháp theo unit (English Grammar for Flyers 1 & 2), bài tập có chấm điểm và giải thích, trò chơi ôn tập, học mỗi ngày và luyện Speaking đúng form Flyers.

Made by Pham Thi Ngoc Bich

## Cách đưa lên GitHub Pages
1. Tạo repository mới trên GitHub (ví dụ `flyers-academy`).
2. Tải 3 file `index.html`, `.nojekyll`, `README.md` lên nhánh `main` (nút *Add file → Upload files*).
3. Vào *Settings → Pages*, mục *Source* chọn *Deploy from a branch*, nhánh `main`, thư mục `/ (root)`, bấm *Save*.
4. Chờ 1–2 phút, web chạy tại `https://<tên-github>.github.io/flyers-academy/`.

## Lưu ý
- Toàn bộ CSS, JavaScript, dữ liệu và ảnh (bìa unit + tranh minh họa lấy từ sách) đã nằm trong `index.html`, nên không cần thêm file nào khác.
- Dùng Chrome hoặc Edge để có giọng đọc nữ Mỹ và micro luyện nói. Bấm nút "Giọng đọc" để chọn giọng (Google US English, Microsoft Aria/Jenny, Samantha).
- Điểm số lưu trên trình duyệt của từng học sinh.

## Bài tập trong sách
Mỗi Lesson có mục **Bài tập trong sách**: trang bài tập dựng lại từ sách, bấm câu tiếng Anh để nghe giọng nữ Mỹ, làm và bấm Chấm điểm. Một số bài (viết lại câu, bảng) dùng 'Xem đáp án' để tự đối chiếu.
