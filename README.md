## Chạy / đăng lên GitHub Pages
1. Tạo repository, tải 3 file (`index.html`, `README.md`, `.nojekyll`) lên.
2. Settings → Pages → Branch: `main`, thư mục `/ (root)` → Save.
3. Mở link GitHub Pages. Chỉ cần file `index.html` (đã gộp sẵn mọi thứ).
